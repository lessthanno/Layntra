LAYNTRA FOR FIGMA — INSTALL

1. Unzip this download. Do not import the ZIP file itself.
2. Open a Design file in Figma Desktop.
3. Choose Plugins > Development > Import plugin from manifest...
4. Select manifest.json in this folder.
5. Run Layntra for Figma once. It connects automatically by default.
6. Use Open Layntra in Figma Properties for quick access later.

Full setup:
